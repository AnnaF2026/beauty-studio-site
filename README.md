# Сайт студии «Я здесь надолго»

Статический сайт на HTML, CSS и JavaScript для GitHub Pages.

После загрузки файлов в публичный репозиторий `main` автоматически публикует сайт с помощью GitHub Actions.

В репозиторий входят только сайт, файл автоматической публикации и фотографии из `assets/`. Таблицы, пароли, ключи и черновики не добавлены.
